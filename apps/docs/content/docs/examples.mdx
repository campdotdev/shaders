# Examples

This page is a placeholder. Curated examples — hero sections, section backgrounds, interactive cursor effects, multi-component compositions — land here after the launch milestone.

In the meantime:

- The [component pages](/components) each include a live demo, a props playground, and the exact source the CLI copies into your project.
- The [primitives pages](/primitives) show the lower-level TSL building blocks. If you want to write your own shader, start there.
- The [Shared scenes guide](/guides/shared-scenes) shows how to combine multiple Matter components inside one `<ShaderScene>`.

If you build something with Matter, [open a PR on GitHub](https://github.com/lovo-hq/matter) — selected examples will land on this page.
