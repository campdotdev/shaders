Add Blobs: soft gooey metaballs that drift around the center, merging and splitting as they meet. Up to 20 blobs with per-blob size variation, a fractional animatable count, softness from crisp gel to mist, depth shading along the color ramp, and a transparent background so the goo stacks over any other layer. Install with `matter add blobs`.
