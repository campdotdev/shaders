Add FractalNoise: a layered multi-octave noise background with a style dial running from soft clouds through folded smoke billows to crisp veined marble, octave and detail dials for how much fine grain shows, and the shared ramp shaping set (stops, contrast, balance, softness, colorSpace, hueInterpolation). Install with `matter add fractal-noise`.
